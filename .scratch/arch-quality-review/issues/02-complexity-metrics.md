# 02 确定性层：复杂度度量（行数/圈复杂度/超阈值清单）

Status: needs-triage

## 描述

新增 `lib/metrics.mjs`：基于现有 tree-sitter 语法树计算——函数/方法行数、文件行数、圈复杂度（分支计数）；聚合分布（总量、均值、中位、Top N）与超阈值清单（带文件:行号）。阈值常量内置（建议起点：函数行数 >80、圈复杂度 >15），可调。

## 建议处置

- 复用 `lib/static.mjs` 的符号遍历逻辑，在符号上挂度量，避免第二遍全量解析；
- 输出：metric 数组（函数/文件粒度）+ 超阈值清单 + 分布摘要。

## 验收标准

- smoke 通过；fixture 上超阈值清单命中预期条目，证据带文件:行号。
