# 06 agent 语义层：检查清单 + 「架构与质量评审」节 + 跨轮趋势对比规则

Status: needs-triage

## 描述

语义层落地（ADR-0005），无插件改动：

1. systemPrompt 增加「架构与质量评审」节指引：架构梳理（依赖图/模块边界观察）→ 优化项清单（高/中/低分组，每条=证据〔文件:行号+度量数字〕+判断+建议）→ 与接手方案衔接；检查项借鉴 dependency-cruiser/ArchUnit 规则语义——依赖环、孤儿模块、可达性、分层违规、超阈值复杂度、重复片段；风格类主观项不列入优化项；
2. 复验跨轮趋势规则：agent 对比两轮事实包（新环/消失环、复杂度增减、依赖增删）写入评审节；「未检查」绝不表述为「无」；
3. 报告结构对齐 ATAM 骨架简化版（证据→敏感点→建议），问题清单与优化项清单分表呈现。
