# ADR-0003 路径语义：验收目录由用户提供，产物随插件工程

- 状态：已接受（2026-08-16）
- 相关：ADR-0001（原生内建）

## 背景

初版把 `projectRoot`/`outDir` 固化在 preset 组合的 `config` 中，指向特定机器路径。开源分发后这些路径对他人无意义；且把「交付物目录」与「需求/合同目录」混进一个 projectRoot 相对基准，与甲方实际使用方式（两个独立来源）不符。

## 决策

1. **交付物目录**（供应商交付）与**需求/合同目录**（甲方基线，可选）是两个独立来源，**验收时由用户分别提供**（绝对路径）；插件不预设任何固定数据根目录；
2. **验收产物随插件工程**：产物根缺省为插件工程根下的 `acceptance/`（gitignore，不入库），可用 `config.outDir` 覆盖；
3. 组合配置**零必填**；agent 在验收前向用户询问两个目录。

## 后果

- 插件开箱即用，无机器相关配置；
- 产物与插件工程同生命周期：工程目录移动/删除会带走历史轮次——跨轮复验依赖产物留在原位；
- agent 每次验收需与用户确认两个目录路径（多一次交互，换取零配置与来源清晰）。
